# Code of conduct

This project follows the
[CNCF Community Code of Conduct](https://www.cncf.io/community/code-of-conduct/).
Everyone taking part in project issues, pull requests, reviews, and other
project spaces is expected to follow it.

Adopting this code does not mean that gateway-api-openstack is a CNCF or
Kubernetes project. It is currently an independent repository.

## Reporting an incident

Do not report a conduct incident in a public issue. Contact an approver listed
in `OWNERS` privately using the contact information on that person's GitHub
profile.

The project currently has one approver and no independent project escalation
contact. If a report concerns that approver or no private contact is available,
use [GitHub's abuse reporting path](https://support.github.com/contact/report-abuse)
for conduct on GitHub. Do not send an incident from this independent repository
to the Kubernetes or CNCF conduct committees. Adding a neutral project contact
is part of the governance work as the maintainer group grows.

For conduct in a Kubernetes community space, use the
[Kubernetes Code of Conduct reporting process](https://kubernetes.io/community/code-of-conduct/).
The Kubernetes Code of Conduct Committee does not administer ordinary activity
in this independent repository.

Maintainers will share a report only with the people needed to review it. They
may remove content, restrict participation, or take other proportionate action
to keep project spaces safe.
